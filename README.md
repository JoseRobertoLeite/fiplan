# Fiplan

Central de ajuda e documentação do sistema Fiplan, desenvolvida como apoio ao conhecimento e uso do sistema no contexto de um projeto de teste em andamento no IFMT.

## Visão geral

O Fiplan é um sistema pensado para organizar, documentar e facilitar o uso de funcionalidades relacionadas ao planejamento e ao acompanhamento de atividades acadêmicas/projetuais. Esta documentação funciona como uma central de apoio para orientar usuários, colaboradores e mantenedores sobre o funcionamento do sistema.

Este repositório está em fase inicial e pode ser expandido com:
- instruções de uso;
- descrições de módulos e funcionalidades;
- fluxos de operação;
- troubleshooting;
- documentação de desenvolvimento;
- referências de apoio ao sistema.

## Objetivo

O objetivo principal desta central de ajuda é:
- facilitar o entendimento do sistema Fiplan;
- reunir informações importantes para uso e manutenção;
- apoiar novos usuários e integrantes da equipe;
- documentar o processo de desenvolvimento e evolução do sistema.

## Contexto do projeto

O projeto foi desenvolvido no contexto de um sistema de teste em andamento no IFMT, com foco em apoiar o conhecimento e a estrutura do sistema Fiplan. O repositório atual serve como base para a documentação e organização do projeto.
